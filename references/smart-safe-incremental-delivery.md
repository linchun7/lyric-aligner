# Smart 安全增量交付

本阶段产出具体可用字幕：Smart 加上已审定的安全增量。确认一条保留一条，其余继承原 floor；有既有 Best-Safe 成品的任务继续继承它已经采用的修复。交付修订号、Smart 算法版本、Best-Safe selector policy 分别记录。当前任务交付修订为 `2026-09-13.5`，Smart 仍为 v1.2.11。

## 逐条判断

- 先说明原字幕具体错在哪里、改后哪个词或归属变正确。降低 review 数、ASR 距离变小、模块或测试增多都不能替代这一判断。
- canonical、实际局部音频、editor 与前后文各自提供证据；不熟悉该语言的人工听审只作有不确定性的参考。原始人工选择、用户补充的可信度限制、机器输出分别保留，不互相冒充。
- 多个裁片使用同一个 ASR，属于相关观察，不能算多个独立真值。无关署名/片尾文本等识别失败不能用来改字幕。置信度数值不能直接解释为正确概率。
- 对具体充分确定的修改，最小必要验证完成后即可交付；无须凑齐49组、完整 blind 或统计显著性。若要把经验推广为自动默认规则，才需要另行证明泛化与无退化。
- 修改限于已有任务明确 review 的位置。任务级局部音频审定与纯文字自动 gate 分开记录；不得修改旧 Smart report、篡改 resolved anchor、调整 DP 阈值或伪造 gate PASS 来让提案通过。
- 一处原位错词的证据不能授权整行替换、删重复、跨 cue 搬词、改时间或拓扑。每条最终采用与拒绝均绑定输入哈希、canonical 位置、原文字、实际音频观察及理由；有反证逐条回滚到父 floor。
